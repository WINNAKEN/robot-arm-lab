# CAN 부품 도착 전 조립·전원 점검 체크리스트

작성: 2026-10-26 / 사용 예정: 2026-10-27 저녁. 실행 기록은 아직 NOT_RUN.
대상: 도착한 MKS SERVO42D CAN MT 2세트. 보정·모터 운전 명령·원점 복귀·플래시·ESP32 연결은 제외한다.

## 시작 경계

- [ ] 모터/드라이브를 A, B로 구분하고 라벨·단자·HW/FW 사진을 남긴다.
- [ ] 실제 CAN 모델인지 확인한다. 사진과 단자명이 다르면 연결하지 않는다.
- [ ] 전원 투입만으로 기존 설정에 의해 축 잠김·움직임이 생길 수 있음을 이해했다. CAN 미연결은 토크 차단이 아니다.
- [ ] **축 움직임을 전혀 허용할 수 없는 조건이면 아래 무전원 조립·전원장치 단독 확인까지만 진행하고, 드라이브 전원 투입은 보류한다.**

## A. 무전원 조립

- [ ] 전원장치 출력 OFF, 드라이브 전원 미연결.
- [ ] 브래킷을 작업판/클램프에 고정하고 모터를 고정한다. 손으로 들고 점검하지 않는다.
- [ ] 실물 나사 깊이를 확인한다. 가정 치수의 M3×10 등을 그대로 적용하지 않는다.
- [ ] 축에는 링크·풀리·감속기·하중을 달지 않고 주변 공간을 확보한다.
- [ ] 출고 조립된 드라이브/엔코더/자석을 분해하거나 조정하지 않는다.
- [ ] 출고 모터 커넥터, 전선 손상·풀림, 도전성 이물·금속 접촉을 확인한다.
- [ ] ESP32/CAN/STEP/DIR/EN 및 외부 제어선을 연결하지 않는다. EN 미연결을 비활성 보장으로 해석하지 않는다.

## B. 전원장치 단독 확인

- [ ] 드라이브와 분리한 상태에서 전원장치 출력 12V 설정. SERVO42D 자료 범위는 12~24V이며 실물 표기도 확인한다. **32V 금지.**
- [ ] 멀티미터로 실제 출력 전압과 극성을 확인한다. 계측기가 없으면 드라이브 투입은 보류한다.
- [ ] 전류 제한은 화면 점검 목적의 낮은 값으로 시작하며, 검증된 구동 설정으로 간주하지 않는다. 반복 재부팅/CC이면 OFF 후 원인 확인; 임의 증대하지 않는다.
- [ ] 출력 OFF로 되돌린다.

## C. 드라이브 1세트 전원 배선 — 계속 출력 OFF

```text
DC + ── 적합한 인라인 퓨즈 ── 실제 V+ 단자
DC − ───────────────────── 실제 GND 단자
```

- [ ] A만 연결한다. 위치·색 추측 대신 실물 V+/GND 표기로 대조한다.
- [ ] 퓨즈는 실제 선재·단자·예상 소비에 맞춰 선정한다. 세트의 10~30A를 임의 적용하지 않는다. 정격 미확정이면 투입 보류.
- [ ] 노출 도체를 절연하고 케이블 당김·클립 이탈·단락을 방지한다.
- [ ] 출력 OFF 버튼을 즉시 누를 수 있다. 불명확한 릴레이/정지회로는 이번 배선에 추가하지 않는다.

## D. 조건부 짧은 화면 확인 — 운전 명령 없음

무전원 점검 통과와 예상치 못한 축 동작에 대비한 고정·빈 공간이 선행 조건이다. 무동작 보장 시험은 아니다.

- [ ] 축에서 손·공구를 치우고 아무 드라이브 버튼도 누르지 않은 상태에서 출력 ON.
- [ ] 화면, 오류/보정 요구 문구, 표시 가능한 FW, 전원장치 V/A를 사진으로 기록한다. 메뉴 변경은 하지 않는다.
- [ ] CAL·보정·홈·영점·시험 회전·공장초기화를 실행하지 않는다. 보정 안내만 나와도 기록 후 종료한다.
- [ ] 움직임·떨림·이상음·냄새·급격한 발열·반복 재부팅이면 즉시 출력 OFF. 축을 손으로 잡아 멈추지 않는다.
- [ ] 화면 확인 후 출력 OFF, 화면 소등과 잔류 전압 해소를 확인한다. 전원이 켜진 채 커넥터를 뽑거나 꽂지 않는다.
- [ ] A를 분리한 뒤 B에 대해 같은 순서 반복한다. 동시 급전은 하지 않는다.
