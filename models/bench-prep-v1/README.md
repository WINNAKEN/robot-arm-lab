# 2축 벤치 출력 보조품 v1

이 폴더의 3종은 이 프로젝트에서 새로 설계한 **비하중 정리용 부품**이다. 받은 로봇 CAD를 복제하거나 변형한 부품이 아니다. 모터·로봇 링크를 지지하는 구조물이나 전기 안전 부품으로 쓰지 않는다.

사용자 확인: **Bambu H2D / PLA**. 노즐 지름·빌드 플레이트·정확한 PLA 제조사/종류는 미확인이다. 0.4mm 노즐·0.2mm 레이어를 사용하는 후속 슬라이스가 있으면 준비용 가정이며, 실제 장비 설정을 확인한 뒤 사용한다. 이 생성 스크립트는 슬라이싱·프린터 연결·출력 작업을 하지 않는다.

| 파일 이름 | 외형(mm) | 먼저 시험 | 이후 수량 | 용도와 확인할 것 |
|---|---|---|---|---|
| `cable_tie_mount` | 24×18×5 | 1개 | 필요하면 총 4개 | 5×2mm 타이 통로, 양쪽 Y면 개방. 4mm 폭 타이를 넣어 보고 통로 천장의 5mm 브리지와 실물 타이 두께를 확인한다. |
| `wire_label_tag` | 40×16×2 | 1개 | 총 6개 | 5×3mm 관통 슬롯. 평면에 J1/J2/CAN/+24V/0V 등을 펜·스티커로 표시한다. |
| `parts_tray` | 90×60×12 | 선택 1개 | 총 1개 | 벽·바닥 2mm, 내부 86×56×10mm. 작은 나사 정리용. |

고정대는 평평한 바닥에 양면테이프로 고정하거나 별도 타이로 타공판에 고정하는 후보이다. 실제 타공판 구멍 배치와 타이 경로를 먼저 맞춰 본다. 케이블은 느슨하게 정리하며 최소 굽힘 반경은 실제 배선에서 확인한다. 인증된 스트레인 릴리프·활선 단자 절연 커버로 간주하지 않는다. 태그의 빈 표시 면적은 기본 치수에서 x=9..39, y=2..14, 즉 30×12mm다. 트레이에는 작은 체결품만 보관한다.

## 파일 선택

- `.stl`: 슬라이서에 가져올 삼각형 메시. **단위를 mm로 확인**한다(STL 자체는 단위 메타데이터 없음).
- `.step`: 다른 CAD에서 열 수 있는 솔리드 교환 형식. 생성 성공을 확인했으며 외부 CAD 호환성 검증은 미실시다.
- `.solidcraft`: 파라미터와 스케치·돌출·절삭 이력이 있는 편집 원본. 기존 SolidCraft 0.18.2에서 생성했다.
- 같은 이름의 `.json`: SolidCraft에서 다시 실행할 수 있는 명령 원본. 치수 표현식이 파라미터에 연결되어 있다.
- `preview.png`: 3종의 등각도와 정면/평면도. 모든 부품은 **평평한 바닥 Z=0을 베드로 향하게** 배치한다.
- `validation.json`: 내보낸 STL을 다시 읽어 검사한 결과·치수·체적·구멍과 벽의 기하 샘플·파일 SHA-256. 실제 출력 성공 증거는 아니다.
- `*_build.json`: SolidCraft 실행 결과 원본. `*_iso.png`, `*_front.png`, `*_top.png`는 CLI로 렌더한 원본 이미지다.

## 치수 수정·재생성

정본 치수는 [`parameters.json`](../../src/cad/bench-prep/parameters.json), 생성기는 [`build_models.py`](../../src/cad/bench-prep/build_models.py)다. mm 단위 양수만 허용한다. 치수 파일을 수정하고 아래를 저장소 루트에서 실행하면 동일한 이름의 출력물을 다시 만든다. 기존 배포물과 비교하려면 `--output`에 별도 폴더를 지정한다.

```powershell
& C:/projects/printforge/.venv/Scripts/python.exe src/cad/bench-prep/build_models.py --solidcraft C:/tools/SolidCraft-0.18.2/solidcraft-0.18.2-windows-x64-portable/solidcraft-cli.exe
```

필요한 기존 로컬 도구: Python 3.12, numpy, trimesh 4.12.2, Pillow 12.3.0, SolidCraft 0.18.2 CLI. 설치·네트워크 접근은 스크립트에 없다. `floor`는 SolidCraft 예약어라 CAD 내부 파라미터 이름만 `base_t`로 변환한다. 다른 치수는 JSON과 CAD 이름이 같다. CAD 화면에서만 바꾼 값은 정본 치수 JSON에 자동 반영되지 않으므로 재생성 전에 JSON에도 옮긴다.

STL의 유한 좌표·닫힌 표면·일관된 삼각형 방향·연결체 1개·양의 체적·정확한 외형·기본 직육면체에서 구멍을 뺀 체적을 검사했다. 타이 통로 양 끝, 태그 관통 구멍, 트레이 내부와 바닥/벽을 실제 STL의 winding number로 검사했다. 물리 출력·맞춤·강도는 **NOT_RUN**이다. 후속 슬라이스의 시간·중량·설정은 별도 결과를 참고하며 실제 출력 전 첫 샘플을 확인한다.
