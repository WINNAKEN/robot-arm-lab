# MKS SERVO42D 실측 기록지 (MP8 · 계획 046)

도착한 모터 두 세트(A · B)를 **전원 없이** 캘리퍼로 재서 적는 종이입니다. 적은 값은 채팅으로 알려 주시면 Claude 가
모터 원장(`src/cad/calibration/motor-mks42d.json`)에 원문 그대로 옮기고, 영향 표(`src/cad/design-check-mp8/motor_impact.py`)를 다시 냅니다.

지금 모든 모델(v1 개념 · v2 · v3 외장 · J2 분할 · 사이클로이드 감속기 · MP5 부하 계산)이 아래 "지금 가정" 값으로 그려져 있습니다.
관절 거리를 그대로 두는 지금 배치에서 **몸체 길이**의 상한은 드라이버 18 · 간격 2 가정 아래 다음과 같습니다 — 실측한 1 · 2 · 3 을 원장에 넣고 영향 표를 다시 냅니다.

- 43 을 넘으면 J1 드라이버가 발(높이 12)에 들어감 — 발을 파지 않으면(파면 바닥 기준 51)
- 43.2 를 넘으면 v3 J4 끝 덮개(민트 사선 0.8 돋움)가 J3 드럼에 닿음
- 43.5 를 넘으면 J2 분할 덮개 기둥 끝(보수 기준) — J2 분할을 다시 그리면 풀림(커넥터 44 · 드라이버 47)
- 44 를 넘으면 v2 꼴 J4 끝 덮개가 J3 드럼에 닿음 · 49.2(v3) / 50(v2) 에서 J6 ↔ J5 드럼

전체 길이(4번 = 1 + 2 + 3)로 보면 위 상한에 20 을 더한 값(63 · 63.2 · 63.5 · 64)이며, 이것은 간격 · 두께를 어떻게 나눠 읽든 같습니다.

## 지킬 것

- 전원 · CAN · 보정(CAL) · 시험 회전을 하지 않습니다. 드라이버 덮개 · 보드 · 엔코더 · 자석을 열거나 풀지 않습니다(분해 금지는 Codex 점검표 `docs/specs/bench-no-can-checklist.md` 의 A 절과 같음).
- 전원을 넣지 않으므로 캘리퍼로 잴 때 모터를 손에 들어도 되고, 시험 조각을 잠깐 끼워 봐도 됩니다(A 절의 「손으로 들고 점검하지 않는다」 는 뒤의 전원 투입을 위한 고정 조건).
- 축에 시험 조각을 끼울 때는 손으로 가볍게만 — 억지로 누르지 않습니다. 끼운 것은 다시 뺍니다(설명서: 보정은 아무것도 달지 않은 상태에서).
- 사진 이름: `A-label.jpg` · `A-side.jpg` · `B-label.jpg` … (세트 · 무엇).
