# 끼움 시험편 세트 v1 (MP4 A1 · 2026-10-23) — 「L4 R2 검수 — 배송 가 · 실물 판정 전」

H2D + PLA 에서 실제로 뽑아 1:1 부품의 구멍 · 끼움 치수를 정하려는 작은 시험편 15 개입니다. 계획 = `docs/design/014-product-exterior-v2-display-kit.md` 의 A1.

## 출력하기

- 파일: `slicer/fit-coupons-v1-plate.bambu.3mf`(G-code 없는 뱀부 스튜디오 프로젝트 — 열어서 슬라이스 · 출력) 또는 `fit-coupons-v1-plate.stl`(셸 15 개).
- **조건(고정)**: Bambu Lab H2D 0.4 nozzle · 0.20mm Standard @BBL H2D · Bambu PLA Basic @BBL H2D · Textured PEI Plate · 지지대 없음(견적이 지지대를
  권하지 않음). 이후 1:1 부품도 같은 조건으로 뽑습니다 — 바꾸면 끼움을 다시 재야 합니다.
- 견적(뱀부 스튜디오 · 실측 아님): **1 시간 27 분 36 초 · 43.11 g · 14.23 m**(`slicer/print_prep_report.json`). 판 위 크기 249 × 237 × 10 mm.
  첫 슬라이스가 1 시간 31 분 34 초여서 계획의 자를 차례대로 ⑤ 의 모터 축 D5 줄을 뺐습니다.
- 출력은 사용자가 합니다(이 작업은 프린터로 보내지 않았습니다).

## 시험편과 기록지

숫자는 모델 치수 그대로 새겼습니다(지름 기준 — ④ 만 반지름 틈). 판정 말 = 「안 들어감 / 눌러 넣음(손 힘) / 손으로 미끄러짐 / 헐거움」.
**오늘 판정할 수 있는 것** = ④ · ⑤(출력물끼리 짝) · ③ 의 인서트 구멍(가진 부품 = M3 열압입 인서트). 나머지는 캘리퍼로 출력 치수만 적어 두고 부품이 오면
판정합니다.

| # | 시험편(파일) | 모델 치수 | 짝 부품 · 지금 | 판정 · 기록 칸 |
|---|---|---|---|---|
| ① | `C1_NEMA17_PLATE_1…3` 판 셋(두께 3) | 파일럿 관통 Ø22.15 / 22.30 / 22.45 · M3 통과 Ø3.4 네 개(31 mm 정사각) | NEMA17 모터 — 없음 | 지금: 파일럿 구멍 지름 실측 ___ / ___ / ___ · 모터 오면: 보스가 들어가는 가장 작은 판 ___ |
| ② | `C2_BEARING_608_SEAT_1…4`(높이 5) | 자리 Ø22.00 / 22.10 / 22.20 / 22.30 · 608 = 8 × 22 × 7 | 608 베어링 — 없음 | 지금: 자리 지름 실측 ___ · 베어링 오면: 손 힘으로 눌러 넣어지는 자리 ___ |
| ③ | `C3_M3_HOLE_BLOCK`(높이 10) — 글자 C · T · I | 세로: 통과 C Ø3.2 / 3.4 / 3.6(관통) · 셀프탭 T Ø2.5 / 2.7 / 2.9(깊이 8) · 인서트 I Ø4.0 / 4.2 / 4.4(깊이 8) · 앞면에 같은 아홉을 가로로(깊이 10) | 인서트 — **있음**(길이 ___ mm) · M3 볼트 — 없음 | 인서트: 인두로 넣었을 때 곧게 · 단단히 들어가는 구멍 — 세로 ___ · 가로 ___ / 나머지: 구멍 지름 실측 |

| ⑤ | `C5_D_HOLE_PLATE`(두께 5 · 왼쪽부터 1 · 2 · 3) + `C5_D_PIN_6_1 · 2` | D6 구멍: 반지름 3.10 / 3.20 / 3.30 · 평면에서 먼 쪽까지 5.20 / 5.40 / 5.60 · 핀 = 반지름 3 · 평면 5 · 길이 20(평면을 판에 눕혀 출력) | 출력물끼리 | 구멍마다 판정 ___ / ___ / ___ → 돌지 않는 핀 · 맞춤 키 틈 결정 |

결과를 알려 주시면(사진 + 위 칸) 1:1 부품의 구멍 · 끼움 값을 정해 `src/cad/armold-mks-product-v2/parameters.json` 에 넣습니다.

## 판정 기록 (2026-10-25 · 사용자 손 판정 · H2D · 0.20 Standard · Bambu PLA Basic(AMS A4 초록) · 텍스처 PEI)

사용자 말 원문은 「」 안 그대로 — 캘리퍼 실측은 아직 없다.

| # | 시험편 | 판정 |
|---|---|---|
| ① | 파일럿 22.15 / 22.30 / 22.45 | 모터 없음 — 끼움은 미판정 · 버니어 안지름(「정확하지는않아」): **21.9 / 22.0 ~ 22.05 / 22.2** → 셋 다 모델보다 약 0.25 작게 읽힘(두께 3 판 · 버니어 안쪽 날은 작게 읽는 쪽이라 일부는 재는 오차일 수 있다) |
| ② | 608 자리 22.00 / 22.10 / 22.20 / 22.30 | 「0.1은 일반적으로 + 공차줫을정도고 0.0 은 좀 억지끼움이였어」 → **Ø22.00 = 억지끼움 · Ø22.10 = 보통 끼움**(22.20 · 22.30 은 말 없음) |
| ③ | 인서트 I Ø4.0 / 4.2 / 4.4(세로 · 윗면) | 「일단 오른쪽 가장큰건너무 컷고 중간건 가이드가 되진못햇어」 → **Ø4.4 너무 큼** · 정정 「Ø4.0 인서트도 잘 들어가네 아까 4.2를 테스트를 실수로 m4로 했나봐」 → **Ø4.0 = M3 인서트 잘 들어감(확정)** · Ø4.2 는 M4 인서트로 시험한 것이라 무효(M3 로는 아직 안 봄) |
| ④ | 링 Ø40.20 / 40.40 / 40.60(반지름 틈 0.10 / 0.20 / 0.30) | 셋 다 「헐거움」 |
| ⑤ | D 구멍 1 / 2 / 3(반지름 3.10 / 3.20 / 3.30 · 평면까지 5.20 / 5.40 / 5.60) · 핀 둘 | 1 = 「하나는 꽉물려서 꽉이고 하나는 살짞 안들어갈랴는거 겨우밀어넣는수준」 · 2 = 「하나는 조금 헐겂게 들어가고하나는 조금더 덜 헐거움」 · 3 = 「헐거움」 → **반지름 틈 0.10 = 억지 · 0.20 = 조금 헐거움 · 0.30 = 헐거움**(누운 채 출력한 핀 기준) |

**값은 끼움 보정 원장 `src/cad/calibration/print-fits.json`(PLA) 하나에서 관리한다** — 판정 원문 · 지금 값 · 상태 · 바꾼 기록이 거기 있다(2026-10-25 사용자
요청). 이 표는 시험편 쪽 기록이고, 생성기는 원장만 읽는다.

쓰인 곳(작성자 해석 — 직접 짝이 맞는 것만 값으로):
- ② → 사이클로이드 시제품(MP6) `bearing_seat_extra` 0.0 → **+0.1**(구매 베어링 · 세로 자리 · 같은 조건 — 바로 쓸 수 있다).
- ③ → MP6 `insert_hole_dia` 4.2 → **4.0 · 확정**(Ø4.0 에 M3 인서트가 잘 들어감 · Ø4.2 의 「잡아 주지 못함」 은 M4 인서트로 시험한 것이라 무효).
- ① → MP6 `pilot_hole_dia` **22.3 유지**: 실측 22.0 ~ 22.05 면 NEMA17 보스 Ø22 에 거의 딱 맞는다. 파일럿이 헐거우면 모터 축(편심 축)이 핀 원 중심에서 그만큼 비켜
  원판 ↔ 핀 보장 틈(0.0885)을 먹으므로 헐겁게 키우지 않는다 — 모터가 오면 22.15 / 22.30 / 22.45 판에 실제로 끼워 확정.
- ④ · ⑤ 는 인쇄물끼리 짝이라 금속 핀 · 모터 축 값으로 바로 옮기지 않는다 — 감속기 판의 맞춤 확인 판(강철 핀 · 베어링 · 모터 축)으로 판정. 참고: 세로 Ø40 의 반지름 틈 0.10 은 이미 흔들리고, 누운 D 핀은 0.10 에서 억지.

## 만든 방법 · 검사

- 생성기 `src/cad/fit-coupons-v1/build_coupons.py`(SolidCraft CLI — 편집 이력 있는 `fit-coupons-v1.solidcraft` · STEP · 부품마다 STL · `coupons.json`).
- 출력 전 판정 `src/cad/fit-coupons-v1/check_coupons.py` → `validation.json`: 부품마다 닫힘 · 체적 양수 · 셸 하나(속 빈 공간 없음) · 바닥 z = 0 · 판 셸 15 =
  부품 15 · 판 크기가 H2D 프로필(350 × 320 × 325 — MP1 슬라이스 보고서) 안 · 설계 치수로 계산한 최소 재료 두께 2.0 mm ≥ 1.2(③ 의 막힌 구멍 밑바닥 — 구멍 사이는 2.35 · 첫 기록은 바닥을 빠뜨려 2.35 였다(L4 R1 F3) · 새김 글자 제외 — 글자는 높이
  3 ~ 3.5 · 깊이 0.6, 못 읽히면 점 개수와 놓인 위치로 가립니다). 구멍마다 축과 Z 의 각도 = `coupons.json`(세로 0° · ③ 의 가로 줄과 D 핀 90°).
- 슬라이스 실행기 `.dev/fit-coupons-evidence/slicer/run_slice_prep.py`(MP1 과 같은 꼴 — 명령 · 모델 해시 전후 · 종료 값 · 보고서 해시 · 프로젝트에
  G-code 없음 확인) → `slicer/slice_manifest.json`.
- 재지 않은 것: 실제 출력 · 끼움 · 글자가 읽히는지(출력 뒤 사용자).
