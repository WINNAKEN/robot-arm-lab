# 009 — 2축 벤치 출력 준비

상태: **MP1_PREPARATION_READY**, L2 R1 PASS(MET5/UNMET0)·L4 R1 PASS(MET7/UNMET0), 2026-10-23. 사용자 요청: “다음으로 진행할 건 모델링 뽑아놓을 것들 슬슬 준비하자”. 실제 출력·맞춤·강도는 NOT_RUN. 결과는 `models/bench-prep-v1/index.html`, 검토 처분은 `.dev/model-prep-evidence/disposition.md`.

## 범위와 현재 가정

사용자가 **2축 시험용 보조부품**, **Bambu H2D·PLA**를 확인했고 PrintForge와 모델링 프로그램 활용을 권했다. 그 조건으로 부품 도착 전 준비 가능한 비하중 보조품을 만든다. PrintForge의 기존 출력 준비 경로와 설치된 SolidCraft를 활용한다. 0.4mm 노즐·0.20mm Standard·Textured PEI·Bambu PLA Basic은 준비용 가정이며 실제 노즐·판·PLA 제조사·등급은 미확인이다. 로컬 슬라이서에서 파일별 시간·재료 추정치를 얻되 가정을 함께 기록하고 프린터 전송은 수행하지 않는다.

현재 MKS CAN MT 두 세트, 금속 NEMA17 L 브래킷 4개, 외함이 있는 Waveshare CAN-U를 기준으로 한다. 모터 브래킷·보드 외함을 중복 제작하지 않는다. 모터 축/길이/후면 드라이버·전원/퓨즈/K1 정격과 타공판 구멍 패턴은 미확정이다. Armold 전체 CAD는 미확보이며 다른 로봇 설계를 사용자 선택으로 대체하지 않는다.

## 이번 산출물

1. 받은 CAD의 프로젝트별 경로·실제 제조 파일·대체품·라이선스 원본 차이를 담은 목록. ROS 시각화 STL을 출력 부품으로 세지 않는다. 파일 수와 조립 수량은 구분한다.
2. 자체 설계한 비하중 보조품 3종의 mm 단위 STL과 수정 가능한 생성 스크립트/매개변수:
   - 케이블타이 고정대: 바닥 24×18mm, 높이 5mm. 4mm 폭 타이용 가로 통로 5×2mm, 바닥 2mm·상부 1mm. 케이블을 잡는 스냅핏이 아니라 타이로 느슨하게 정리하는 용도. 바닥 양면테이프 또는 타공판에 별도 타이로 고정. 도체/실드 접촉·안전 스트레인릴리프 용도 아님. 케이블 최소 굽힘 반경은 실제 배치에서 확인.
   - 배선 표시 태그: 40×16×2mm 판, 5×3mm 타이 구멍 1개. 30×12mm 내측 평면에 펜/스티커로 J1/J2/CAN/+24V/0V 표시. 전원 단자 커버·절연 인증품 아님.
   - 나사 정리 트레이: 외형 90×60×12mm, 바닥·벽 2mm. 빈 트레이로 출력해 작은 체결품을 보관. 전장품·활선 단자 설치용 외함으로 사용하지 않는다.
3. 파일별 치수·닫힌 메시/연결 성분/체적 결과와 출력 방향 이미지. 케이블타이 통로는 5mm 짧은 브리지로, 첫 1개 시험 슬라이스·출력 후 통과 여부를 확인한다. 다른 두 부품은 평평한 바닥 아래로 출력한다.
4. 보기 쉬운 로컬 HTML 출력 준비표: 먼저 시험할 파일, 권장 수량(고정대1개→필요시총4개 / 태그1개→총6개 / 트레이 선택1개), 실측 후 모델링할 부품, 본체 CAD 확보 현황, 실측 체크 항목. 첫 샘플 확인 전 대량 출력하지 않는다.

## 구현과 확인

- 원본 패키지는 읽기 전용. 별도 `src/cad/bench-prep/`와 `models/bench-prep-v1/`에 생성한다. 펌웨어·구매표·중앙 규율은 수정하지 않는다.
- 기존 설치 SolidCraft CLI로 단순 프리미티브 차집합을 구성하고 STEP·native CAD·STL을 내보낸다. Python의 trimesh로 실제 STL을 다시 읽어 검증한다. CLI가 불가하면 기존 trimesh/manifold3d의 STL+편집 스크립트 경로로 제한하며 STEP 성공으로 쓰지 않는다. 외부 원본 코드를 실행하거나 새 패키지를 설치하지 않는다. 입력 매개변수는 파일에 보존하고 출력물과 근거 해시를 기록한다.
- 실제 내보낸 STL을 재로딩해 유한 좌표·치수·양의 체적·닫힌 표면·일관된 방향·연결 성분 1개를 검사한다. 태그 구멍, 타이 통로, 트레이 내부는 절단면 또는 기하 샘플로 확인하며 메시 검사와 실제 출력 성공을 구분한다.
- 스크린샷/렌더로 형상과 표기/파일 링크를 확인한다. 사용자 조건 확인 뒤 PrintForge로 로컬 H2D 준비용 슬라이스를 수행하며, 결과는 가정된 프로필의 추정치다. 실패가 있으면 우회하지 않고 기록한다. 실제 출력·실물 맞춤/강도는 NOT_RUN으로 남긴다. 완성 로봇 부품은 후보 목록만 제공한다.
