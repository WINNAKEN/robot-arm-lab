# MP18 기반 로봇암 URDF v4

정본은 `robot_arm.urdf`이며 XML을 직접 작성했다. 현재 작업 트리의 `manipulator-v2` 모델과 MP18 케이블 후속 변경을 반영한 별도 판이다. 기존 v1~v3, CAD, 펌웨어와 116 실행 자료는 보존한다.

| 항목 | v3 | v4 |
|---|---|---|
| 팔 형상 | MP7/MP9 외장 | MP18 전면 외장·케이블 후속판 |
| J3→J4 거리 | 140mm | 165mm |
| J2/J3 구동부 | 이전 모형 | MP16 57D 가정·81:1 모듈, J3 모듈 90도 전환 |
| 위팔·어깨·손목 | 이전 외장 | 높이 91mm 위팔·어깨 두건·손목 외장 |
| 질량 | 4.3342kg 임시값 | 8.863854736kg 추정값 |
| COM·관성 | 링크 AABB 근사 | 구성별 원장 질량·메시/상자/점 근사 집계, 전체 3×3 텐서 |
| 그리퍼 | KG1 연동 | 같은 이름·벌림/기어비·184.2g 보존, 구성별 물성 재계산 |

CAD 변경은 STEP/솔리드 재설계 없이 현재 STL과 배치 행렬을 읽어 반영했다. 274개 표시 구성물을 링크별 11개 정본 메시와 47개 색상별 표시 메시로 나눴다. 색상별 메시의 원점은 모두 링크 원점이며, 단위는 m·scale 1이다. 메시를 포함한 이 폴더 전체를 함께 옮긴다.

12개 링크/11개 조인트이며 움직이는 조인트는 9개, 독립 좌표는 팔 6개와 그리퍼 1개이다. `Base`, `Link1`~`Link6`, `KG1`, `KG1_A`, `KG1_B`, `KG1_R`, `tool0` 이름을 유지한다. `tool0`는 질량 없는 명목 파지점이다.

## 좌표와 구동 해석

팔 URDF 0은 CAD 표시 자세 `[15,-50,70,15,25,-10]°`다. CAD 절대각은 URDF 각도에 표시 각도를 더한 값이다. 이 값은 하드웨어 영점이나 모터 부호를 뜻하지 않는다. URDF 파일의 각도는 rad, 길이는 m, 질량은 kg, 관성은 kg·m²다. 팔 양의 회전은 J1 +Z, J2/J3/J5 +Y, J4/J6 +X에 대한 오른손 방향이다.

| 관절 | CAD 절대각 잠정 범위(°) | URDF 상대각 범위(°) |
|---|---:|---:|
| J1 | -170 ~ 170 | -185 ~ 155 |
| J2 | -100 ~ 0 | -50 ~ 50 |
| J3 | -20 ~ 120 | -90 ~ 50 |
| J4 | -120 ~ 120 | -135 ~ 105 |
| J5 | -90 ~ 90 | -115 ~ 65 |
| J6 | -170 ~ 170 | -160 ~ 180 |

이 범위는 CAD 설계자 제안이며 각 축 단독 표본검사 범위 안의 잠정 운동학 한도다. 조합 자세 전체의 충돌 없는 범위를 뜻하지 않는다. CAD C5에는 J2/J3/J5 일부 자세가 책상 아래로 내려가는 결과도 있다. 관절 한도만으로 책상·외부물체·자가충돌을 피할 수 없다.

그리퍼 기본 벌림은 전체 간격 40mm다. `opening_m`은 전체 간격 0~0.094m이고 독립 좌표는 `KG1_slide_A = opening_m/2 - 0.020`이다. `KG1_slide_B`는 같은 값, `KG1_pinion`은 그 값에 `-1/0.0135`를 곱한다. XML mimic follower를 별도로 명령하지 않는다. A 양의 방향은 G-X, B는 G+X이며 피니언은 G+Y 오른손 회전이다. TCP는 J6 축으로부터 131mm이며 실측 보정값이 아니다.

## 물성·충돌 형상의 가정

MP18 원본 173개 질량을 원래 정밀도로 재구성했다. 개별 4자리 반올림 수의 합은 8.8640kg이고 전체를 나중에 반올림한 원장 총량은 8.8639kg이다. 정밀 총량 8.863854736164349kg은 유지했다. KG1 전체 184.2g 항목 하나를 제거한 후 실제 47개 구성물에 한 번 분배해 총 219개 질량 구성물을 집계했다.

출력품은 슬라이서 질량과 균일 부피 중심/관성, 구매품은 원본 상자 또는 점 근사다. 117개 점 근사 품목은 자체 관성을 0으로 두고 평행축 기여만 포함한다. 무게를 달거나 관성 시험으로 보정한 값은 없다. 그리퍼 안의 서보·혼·나사 질량 배분도 가정이며 `asset-ledger.json`에 전수 기록했다.

그리퍼 세분화로 닫힌 CAD0 전체 COM은 원본 일괄 근사에서 x -7.849µm, y +7.376µm, z -16.857µm 변했다. 6818 베어링은 원본 하중 모형의 질량 Link1/표시 Base 차이를 보존해 출처 차이로 기록했다. 이를 실제 베어링 회전 관성으로 해석하지 않는다. 57D 단자 치수는 원본의 42D 유래 가정이다. 모터 몸체 어림은 표시하되 슬롯 끝·단자 여유 등 중복 검사 envelope는 제외했다. 드라이버 원장 질량은 유지했다.

충돌 메시 11개는 부품마다 계산한 convex hull들을 합친 다중 셸 메시다. 각 링의 구멍이나 가이드 구멍이 닫혀 거짓 접촉을 만들 수 있다. 전체 링크의 단일 convex hull과도 다르다. Isaac의 동적 convex decomposition·접촉·자가충돌은 별도 가져오기 검증이 필요하다.

팔 effort `[3,6,5,2,2,1]Nm`, velocity 0.5rad/s, damping 0.05, friction 0과 기존 그리퍼 cap은 v3 값을 유지했다. 모터 정격으로 사용하거나 새 질량의 중력 유지 능력이 검증됐다고 해석하지 않는다.

## 확인과 사용

로컬 검사: `cad urdf validate models/robot-arm-urdf-v4/robot_arm.urdf --strict --json`. 수치 재검사: 기존 mesh 환경으로 `src/simulation/urdf_mp18_v4/verify.py`를 `-I -B` 옵션과 함께 실행한다. 보조 도구는 원본 CAD와 정본 XML을 작성하지 않는다. `assets.py`는 기존 `numeric-ledger.json`이 있으면 전체 자산 재생성을 거부한다. 명시적 `--finalize-pins`는 출처 핀 메타데이터를 갱신하는 별도 경로다.

수치 검사는 CAD와 79개 팔 자세를 대조하고 그리퍼 0/40/80/94mm의 mimic·실제 원본 기하를 비교한다. 이전 140mm 길이나 반대 관절 부호를 넣는 음성 대조도 포함한다. XML 구조·물성·메시 경로와 전후 원본 보존을 확인한다. 최종 결과와 14개 관절끝 뷰어 검사, 독립 검토 원문은 `outputs/urdf-mp18-v4-118/RESULT.md`를 참조한다. 검사 그림의 Parts 표시 모드는 링크 구분색이며 실제 외장 색의 렌더가 아니다.

`check_urdf`는 설치되어 있지 않아 생략했다. 이번 작업에서 Isaac/USD 가져오기·정지·큰 동작·실물 CAN/RS485는 실행하지 않았다. 기존 원격 실행기는 계속 v3를 가리키며 v4로 자동 전환하지 않았다. v4를 시뮬레이션에 넣을 때는 새 모델 해시·전체 표시 형상·물성·고정 베이스·mimic·충돌 분해를 확인한 뒤 정지 검증부터 진행해야 한다.

`numeric-ledger.json`은 계산 수치, `asset-ledger.json`은 구성물별 질량·기하와 제외 이유, `provenance.json`은 읽은 원본의 해시와 가정이다. 최종 검토는 앞서 승인된 동일 계열 비작성자 폴백을 사용하므로 외부 계열 렌즈 부재에 따른 공통 편향은 남는다.
