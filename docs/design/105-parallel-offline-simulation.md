## 수용과 검증

1. 새 관측은 실제 원자료 경로·SHA·단위·표본 경계를 제시한다. 기존096 재확인과 추가 관측을 구분한다.
2. 34초 이후 다른 축/전체 목표가 바뀐 자료를 고정 목표 hold 연장으로 쓰지 않는다. cap 설정으로 실제 PD토크/포화·유일원인을 단정하지 않는다.
3. 현재 최초 gate와 시계 복구 뒤 필요한 새 namespace/검토/명시45분 승인을 실제 호출 경로로 연결한다. 준비 문서 완성과 native-ready를 구분한다.
4. 주 에이전트가 현재 후보와 실제 실행 영수증/보호 경계를 읽기 대조한다. 기존 HOST 전체를 이유 없이 재실행하지 않는다.
5. 통합 보고 뒤 비작성자 자료 감사 최대2회로 신규 수치·코드 위치·권한 범위를 확인한다. 원자료 재관측은 작성자 분석기 재실행과 다른 기전으로 수행하며, 동일계열 잔여편향/실제 물리 미검증을 명시한다. 이는 099/103/104에 추가 L4 회차를 붙이거나 닫힌 검토를 재개하는 절차가 아니다. 제품 코드 구현은 없으며 후속 구현은 별도 계획·L2/L4 대상이다.

시계 정렬과 새 실행 승인 조건이 충족되기 전에도 이번 로컬 분석·준비는 완료할 수 있다. 실제 원격 실행은 해당 fresh 단위의 준비·검토와 첫 원격부터 새45분 명시 승인을 갖춘 뒤 import→정지 수용→42초 진단 순서로 진행한다.
