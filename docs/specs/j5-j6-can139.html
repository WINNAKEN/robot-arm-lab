J5 · J6는 CAN으로 연결합니다

사용자 확인: J5와 J6 두 대 모두 CAN형. 그리퍼 모터의 통신형과 실제 보드 리비전·전원·모터 정격은 별도 확인 대기입니다. 이 안내는 단자 이름을 기준으로 하며 나사의 좌우 위치를 뜻하지 않습니다.

현재 단계는 준비입니다. 실제 연결·급전·플래시·CAN 송수신·모터 구동은 하지 않았습니다. 처음에는 J5 또는 J6 한 대만 확인하고, 다른 한 대는 전원과 통신에서 분리합니다. J5에는 무급전 처짐을 막을 받침이 필요합니다.

1 · 한 대 먼저, 확인 뒤 두 대로 확장

물리 순서를 J6→J5로 바꾸면 실제 중간/끝 위치에 맞춰 종단도 바꿉니다. 별 모양 배선과 긴 가지는 피합니다. 두 끝에만120Ω이면 전체 무전원 H–L은 약60Ω이며, 저항값만으로 통신 합격을 뜻하지 않습니다.

2 · 전원은 CAN선과 따로 연결

MKS CAN V1.0.9의12–24V는 모델 범위이며 이번 현품 설정 승인이 아닙니다. 모터 상전류와 PSU 입력 전류는 다릅니다. Waveshare USB와 외부DC를 동시 급전하지 않습니다. 외부 H/L만 있는 절연 보드의 SH1.0 GND를 임의 CAN 기준선으로 연결하지 않습니다. 모터 코일 A±/B±, EVCC/EGND/COM은 위 H/L과 다른 단자입니다.

주소 · 소프트웨어 · 시험 순서

관절 이름현재 확인CAN 시험 ID

그리퍼통신형·모터 구성 미확인배정하지 않음
관절 번호와 CAN ID는 다릅니다. 기존 CAN 시험 코드는 ID1/2를 대상으로 합니다. J5라고 ID5, J6라고 ID6을 임의로 넣지 않습니다. 공장 ID가 모두1이면 함께 연결하지 말고 한 대씩 실제 주소를 확인합니다. 이 문서는 주소를 자동 설정하거나 스캔하지 않습니다.

지금 준비된 소프트웨어

  • 기존 src/firmware/diagnostic/의 CAN 읽기 진단 준비물이 있습니다. ID1 또는2를 선택해 enable·운전상태·위치·속도를 읽는 경로이며 실물 허가는 false로 고정돼 있습니다. 바로 플래시해 통신할 수 있는 활성 앱이라는 뜻이 아닙니다.
  • 이 준비 코드의 기대 조건은 CAN-U 보드 / GPIO15 TX·16 RX / 500kbit/s입니다. 실제 보드가 CAN-U인지, 해당 리비전이 맞는지, 드라이버 CanRate와 일치하는지는 미확인입니다. 메뉴·프로필 값을 임의 승인하지 않습니다.
  • 138의 RS485 중계 펌웨어와 FA/FB 프레임을 J5·J6 CAN에 사용하지 않습니다. 138의 자료는 역사적 RS485 준비물로 보존했습니다. 아래 CAN 데이터에는 FA/FB 헤더나 별도 직렬 주소 바이트가 없습니다.

읽기 요청 미리보기 — 전송하지 않은 예시

표준11bit CAN DATA, RTR/EXT=false, DLC2. DATA=[opcode, (CAN ID+opcode)&255]. 실제 FW/프로토콜 확인 전 전송하지 않습니다.

조회ID1 DATAID2 DATA

ID2의 F1 F3에서 F3는 checksum이며 enable 명령이 아닙니다. 정상 checksum이나 읽기 응답만으로 실제 정지·무토크·기구 안전을 판정하지 않습니다.

남은 확인과 이후 순서

  1. 축별 드라이버 HW/FW·단자, 모터 명판 상전류·스텝각, 전원 출력·보호 정격을 확인합니다.
  2. 모터 전원과 H/L을 분리한 보드 단독 상태에서 기존 펌웨어를 확인합니다. 공장 펌웨어가 무동작이라고 가정하지 않습니다.
  3. 전원OFF·잔류전압 없음 확인 후 한 축 결선·극성·단락·종단을 대조합니다. J5를 고정하고 받칩니다.
  4. 별도 실제 시험 범위·프로필을 확정한 뒤 한 축 읽기부터 확인합니다. 정지/차단/복귀와 방향·감속비·여유 확인 뒤에만 별도 작은 이동을 계획합니다. 조립된 기구를 연결한 채 무심코 자동 교정하지 않습니다.
