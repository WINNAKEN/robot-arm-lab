# Armold 타입 MKS 6축 자체 개념 모델 v1

Armold의 컴팩트한 원통 관절·직렬 6축 배치를 시각 참고해 새로 그린 공간 검토용 모델입니다. 유료 Armold CAD나 Faze4 전체 로봇 형상은 사용하지 않았습니다. **제작·출력·하중·장착 승인 도면이 아닙니다.**

- `armold-type-mks-six-axis-concept.solidcraft`: 스케치·돌출·보어 절삭 이력이 있는 69개 B-rep 솔리드. Base + Link1…Link6의 7개 강체 링크, 고정 베이스와 6개 실제 revolute 조인트입니다.
- `armold-type-mks-six-axis-concept.step`: 중립 솔리드 형상. 네이티브 이력·관절은 STEP에 보존되지 않습니다.
- `iso.png`, `front.png`, `right.png`: 표시 자세의 전체 조립 형상입니다.
- `parameters.json`, `kinematics.json`, `validation.json`: 가정 치수·축/원점·검증 근거입니다.
- `reducer-principle-schematic-NONFUNCTIONAL.solidcraft`, `reducer-principle-schematic.png`: 감속 원리용 별도 단면·분해 모형입니다. 작동 치형을 넣지 않은 매끈한 빈 디스크, 외주28핀, 가정 편심 입력, 출력핀/플랜지를 보여줍니다. 부품 간 축방향 간격을 의도적으로 벌렸고 감속비·맞물림·베어링·공차는 미설계입니다. 디스크79.75 mm는 원본 메시의 외접 폭을 참고한 그림용 가정입니다.

## 현재 반영한 주문품과 가정

주문 확정은 MKS SERVO42D **CAN MT 2세트**입니다. 그림의 모터 6개는 향후 구성입니다. 실제 상품의 몸체 길이·축·보드·방열판·커넥터 실측이 없어, NEMA17 프레임42.3 mm / 몸체40 mm / 후면46×46×18 mm / 커넥터 측면12 mm를 가정했습니다. 청회색은 모터, 황토색은 보드/방열판 공간, 옅은 크림색은 커넥터 여유 공간입니다.

관절 외경은 J1/J3 90 mm, J2 104 mm, J4…J6 78 mm입니다. 실측 모터에 체결 가능한 볼트 구멍·커플링·베어링·치형은 설계하지 않았습니다. 갈색 내부 링은 미설계 감속 공간이며 작동 디스크가 아닙니다.

J5→J6 거리는 처음72 mm에서 **140 mm**로 늘렸습니다. 72 mm에서는 약81 mm의 모터+후면 드라이버 축방향 공간이 J5 내부를 관통했습니다. J4 커넥터는 전완 지지대 반대쪽에 두고, J1 베이스 내부 반지름은38 mm로 조정했습니다. 현재 표시 자세에서 모터·드라이버·커넥터와 다른 형상의 체적 간섭은 없으며, 전체 관절 범위는 검사하지 않았습니다. 같은 강체 안의 지지대/하우징 접합·장식 밴드·미설계 코어는 의도적으로 겹칩니다.

## 축과 편집

영점 부모 좌표축 순서는 **Z–Y–Y–X–Y–X**입니다. 손목 축은 서로 떨어져 있으므로 구면 손목이 아닙니다. 그리퍼는 미선정이며 끝단은 수동 공구 플랜지입니다. 7번째 제어축은 없습니다.

원본 생성 자세는 `[15, -50, 70, 15, 25, -10]`도입니다. 네이티브 `J1…J6_CONCEPT_DISPLAY_ZERO`의 **0도는 화면에 표시된 이 자세**입니다. 네이티브 각도를 움직이면 이 자세에서 해당 관절의 증분 회전이 적용됩니다. 전 관절의 ±170도 소프트웨어 한계는 예시이며 실제 기계 허용 범위가 아닙니다. 베이스는 고정되어 있고 말단 링크의 기구학 자유도는6입니다. 소프트웨어 J1 +5도 시험에서 모든 하위 축/원점이 FK 회전과 일치했습니다. 하드웨어에는 접속하지 않았습니다.

네이티브 파라미터의 `motor_frame`, `motor_length`, `driver_width`, `driver_depth`, `connector_clearance`는 실제 스케치/돌출 치수에 연결되어 있습니다. 단, 사용자 파라미터를 바꿔도 고정된 스케치 원점이나 다른 부품의 배치까지 자동 재설계되지는 않습니다. 전체 길이·관절 배치·자세를 바꾸려면 `src/cad/armold-mks-concept/parameters.json`을 수정한 뒤 `build_concept.py --cli <설치된 solidcraft-cli.exe>`로 다시 생성하고 검증해야 합니다. 실제 출력 전에는 치수 실측, 부하/감속비, 베어링 지지와 공차, 나사 체결 및 전체 동작 간섭 검토가 필요합니다.

`base_width_mm`/`base_thickness_mm`는 생성기의 실제 베이스 치수 입력입니다. 기본값140/12 mm 외에 별도 시험에서164/16 mm로 바꿔 생성한 B-rep가164×164×16 mm임을 확인했습니다. `wrist_offsets_mm`는 J4→J5와 J5→J6의 **두 값**만 가지며, 적용되지 않는 세 번째 값은 제거했습니다.
