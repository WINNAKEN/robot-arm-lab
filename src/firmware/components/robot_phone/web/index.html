하드웨어 미승인 · 준비용 빌드
기본 프로필은 CAN/토크/이동을 거절합니다. 실제 Wi-Fi·기계 정지시간 검증 전입니다.

코드와 세션은 저장하지 않습니다. 새로고침 후 다시 연결하세요.

1 · 유지보수

각 단계의 실제 결과를 확인한 뒤 다음 단계를 선택하세요. Busy 거절은 자동 재시도하지 않습니다.

2 · 운전 인계

마지막 버튼은 인계와 정상 제어권 획득을 명시적으로 요청합니다. 서버는 기존 권한 만료와 접수 후700ms 중 빠른 시각 전에 한 번만 획득하고, 화면은 그 결과를 조회합니다. 오류·숨김·정지는 화면의 결과 대기와 이동 권한을 취소합니다. 진행 중인 예약의 정지 식별자는 최종 종료 상태를 확인할 때까지 메모리에 유지합니다. 통신 복구 후에는 정지 상태만 조회하며 자동 이동하지 않습니다.

3 · 고정 100 pulse

한 번 누르면 실제 Arm → Ticket → Move 응답 순서로 실행합니다. 실패·숨김·오래된 상태에서 중단하며 다시 보내지 않습니다.

4 · 숫자로 상대각도 이동

현재 자세에서 이동할 양을 입력하세요. 절대 목표 각도가 아닙니다. 양수·음수는 CAD/코어 관절 방향 기준입니다.

실물 보정 미승인 · 숫자 이동 불가

현재는 보정된 100 pulse 한 번에 해당하는 각도만 허용합니다. 다른 크기는 거절하며 자동 분할·반올림·재시도하지 않습니다.

과거에 수신한 마지막 결과입니다. 현재 연결·안전 상태나 이동 권한을 뜻하지 않습니다. 이 페이지의 메모리에만 보관하며 새로고침하면 사라집니다.
