## 모델링에 옮기는 법 (작성자 제안 — 사용자 확정 전)

| 자리 | 지금(v2 외장 · 계획 014) | 컨셉 적용 제안 |
|---|---|---|
| 링크 셸 · 베이스 하우징 등 큰 외장 | 흰 몸체 | **흰색** 그대로 |
| 관절 색 링 · 끝 덮개 | 주황 | **진한 남색(Deep Navy)** |
| 감속기 하우징 · 브래킷 · 속 기능 부품 | (기능 부품은 PLA 아무 색 — 지금 시험은 초록) | **회색(Cool Gray)** 또는 남색 — 시험 출력은 색을 따지지 않는다 |
| 강조 | 없음 | **민트(Mint Accent)** 를 작은 면에만: 덮개의 45° 사선 띠 · 표시선 · 로고 사선 |
| 로고 | 없음 | 모노그램(K · M · J · H 를 엮은 각진 기호) 또는 가로 로고를 베이스 옆면 · 이름판에 양각 / 음각 · 다른 색 판 끼움 |

형태 단서(그림의 「STYLE CUES」 = Precision · Motion · Trust · Modular 와 로고 모양에서 읽은 것 — 제안):
- 각진 면 + **45° 사선**(로고 K 의 민트 사선 · 모노그램의 꺾인 획) — 둥근 곡면 위주보다 평평한 면과 사선 모따기.
- 모듈 반복 — 관절마다 같은 덮개 · 같은 색 띠 규칙.
- 장비 이름판 예(그림 03): 외장 한 면에 이름판 자리(모델 · 일련번호 · 전압 · 가반)를 두는 것도 가능.

- H2D AMS 로 여러 색을 쓸 수 있다. 실제 필라멘트 색 이름 · 값은 **그때 색상표로 골라** 이 표에 적는다(아직 고르지 않음 · 화면 색 값과 필라멘트 색은 같지 않다).
