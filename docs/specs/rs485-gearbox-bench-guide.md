# 감속기 단품 시험 — 임시 RS485 배선과 최종 CAN 전환

2026-11-05 KST. 사용자 방향: **현재 받은 SERVO42D RS485 MB로 감속기 회전을 확인하고, 최종 로봇 통합은 SERVO42D CAN으로 유지한다.**
이 문서는 연결 준비와 시험 순서를 설명한다. 장치에 연결·플래시·급전·송신·모터 구동을 수행한 기록은 아니다.

## 1. 현재 부품과 코드의 상태

| 항목 | 확인된 상태 |
|---|---|
| 현재 드라이버 | 사용자 보고: SERVO42D RS485 MB가 지금 있음. 실제 단자 사진·HW/FW·모터 상전류 미확인 |
| 최종 드라이버 | 사용자 보고: SERVO42D CAN MB 구매, 최종 CAN 통합 유지. 현품 수령/실물 확인은 별도 |
| 제어기 | 사용자 보고: ESP32-S3-RS485-CAN. 예전 기록의 CAN-U와 구분하며 PCB 개정/실제 단자는 사진으로 확인 |
| 전원공급기 | 예전 주문은 WANPTEK EPS3210이지만 현재 현품·설정·보호/차단·전류제한은 미확인 |
| CAN 코드 | codec/TWAI·Boot/Run/정지·휴대폰 흐름의 HOST/빌드 준비 있음. 실물 CAN·플래시·기계 정지 성능은 NOT_RUN |
| 읽기 진단 | 088 HOST104시나리오/973검사·비활성 ESP32 빌드 성공. CAN 전용이며 실제 통신 결과는 아님 |
| 로그 보고서 | 090 오프라인 보고서 HOST52·독립 검토 완료. 실물 통신 성공을 인증하지 않음 |
| 임시 RS485 제어 | 기존 CAN 실행 경로를 그대로 쓸 수 없음. UART/RS485 프레임·응답·정지/시간제한을 갖춘 작은 시험 도구가 별도로 필요 |

Waveshare 보드는 RS485와 CAN 송수신 하드웨어를 모두 갖지만, 자동 USB–RS485 변환기라고 가정하지 않는다. PC의 명령을 모터용 RS485 프레임으로 중계할 펌웨어가 필요하다. 기존 CAN hex payload를 USB나 RS485에 그대로 보내지 않는다.

## 2. 최초 시험의 범위

처음에는 **모터 한 대만** 고정하고 드라이브 식별·설정과 정지를 확인한다. 그 다음 감속기만 연결해 로봇 링크·하중 없는 저속 단품 시험으로 진행한다. 첫 교정/상 결선 확인은 감속기와 분리한 무부하 상태에서 제조사 조건을 따른다. 교정 기능을 회전 시험 버튼 대신 사용하지 않는다.

RS485 시험으로 볼 것은 회전 가능 여부, 걸림/간섭, 소음·진동, 발열 변화, 출력 방향이다. 유격과 감속비는 출력축 표시나 별도 관찰로 확인한다. 모터 내부 엔코더만으로 감속기 출력축의 위치·유격·하중 성능을 검증했다고 쓰지 않는다.

## 3. 지금 부품의 1축 배선 — ESP32는 USB로만 급전

아래는 단자 **이름** 기준이다. 현품 사진 확인 전 좌/우·위/아래 나사 위치를 확정하지 않는다. 배선·점퍼·모터 커넥터 변경은 USB와 DC를 모두 끄고 잔류 전압이 없을 때 한다.

```text
현재 노트북 ── USB 데이터 케이블 ── Waveshare ESP32-S3-RS485-CAN
                                      │ 상단 DC +/− : 연결하지 않음
                                      │
                         RS485 A+ ─────┼──────── MKS의 RS485 A
                         RS485 B− ─────┼──────── MKS의 RS485 B
                         CAN H/L       │         이번 RS485 시험에서 미사용

별도 DC 전원 + ── [정격 확인한 퓨즈/급전 차단] ── MKS V+
별도 DC 전원 − ─────────────────────────────── MKS GND

MKS 모터 출력 A+/A− ── 모터의 한 코일
MKS 모터 출력 B+/B− ── 모터의 다른 코일
```

| 선 | 출발 | 도착 | 구분 |
|---|---|---|---|
| 통신선 한 심 | Waveshare **RS485 A+** | MKS **RS485 A** | 다음 행과 같은 꼬임쌍 |
| 통신선 다른 심 | Waveshare **RS485 B−** | MKS **RS485 B** | CAN H/L과 혼동하지 않음 |
| DC 전원 + | PSU +, 보호/차단 뒤 | MKS **V+** | 모터 드라이버는 매뉴얼상12–24V. 실제 설정은 현품/모터 정격 확인 후 결정 |
| DC 전원 − | PSU − | MKS 전원 **GND** | V+ 옆 전원 GND. COM과 혼동하지 않음 |
| USB | 노트북 | Waveshare Type-C | 이 구성에서는 Waveshare DC 입력 미연결 |
| 모터 상선 | 드라이버 모터 커넥터 | 각 모터 코일 | 조립 출고품 결선 우선, 선색으로 상을 추측하지 않음 |

**통신 A/B와 모터 코일 A+/A−/B+/B−는 다른 단자다.** MKS의 COM/EN/STP/DIR, EVCC/EGND/IN_1은 이 임시 직렬 제어 배선에서 임의로 연결하지 않는다. EVCC는 매뉴얼상5V/20mA 보조 출력이며 ESP32나 모터 전원으로 쓰지 않는다.

제조사 RS485 매뉴얼에는 USB–RS485 어댑터의 별도 GND를 연결하는 그림이 있다. 현재 Waveshare의 외부 RS485 단자는 A+/B−이고 통신부가 절연되어 있으므로, 그 그림의 GND 선을 SH1.0 GND나 임의 전원 단자로 옮기지 않는다. 통신 절연부 기준과 전원 0V는 구분한다. 절연부 기준선 추가가 필요하면 실제 회로·단자를 먼저 대조한다.

USB는 Waveshare만 급전한다. 모터는 별도 DC 전원이 필요하다. Waveshare 제조사는 USB와 DC 단자 동시 급전을 금지한다. 나중에 DC 단자 급전으로 바꾸려면 USB를 분리한 별도 구성으로 다시 확인한다. 전원장치 최대32V나10A를 모터에 적용할 설정값으로 사용하지 않는다. 퓨즈·전류제한·차단품 정격은 실제 모터/전선/단자 확인 전 미정이다.

## 4. 통신선과 종단

- 기존 선택 기록의 RVSP 4심24AWG를 쓴다면 실제로 꼬인 한 쌍을 A/B로 사용한다. 색만으로 쌍을 추측하지 않는다. 남는 심과 실드를 전원선으로 쓰지 않는다. 상품명만으로120Ω 특성 임피던스가 확인된 것은 아니다.
- 처음에는 짧은 1축 고정 배선으로 시작하고 모터 상선/전원선과 분리한다. 단자 가까이까지 꼬임을 유지한다.
- MKS RS485 매뉴얼 V1.0.9 p19는 단일 장치 연결에서 모터측120Ω 점퍼를 끼우지 않도록 안내한다. 이 짧은 1축 구성은 Waveshare RS485 점퍼도 기본 NC로 두는 준비안이며 실제 PCB 표시를 확인한다. CAN용 점퍼를 조작하지 않는다.
- 긴 선로/여러 노드로 확장하면 종단·바이어스·기준선은 다시 설계한다. CAN의 양 끝120Ω/전체 약60Ω 검사표를 현재 RS485 단일 장치에 그대로 적용하지 않는다.
- 전원·USB를 분리한 상태에서 극성·단락·단자 이름·케이블 장력부터 확인한다. 저항 측정은 무전압에서만 한다.

## 5. 실제 시험 전에 채울 값

| 확인 항목 | 현재 |
|---|---|
| Waveshare와 MKS의 단자 글씨·PCB/HW 사진 | 미확인 |
| MKS About의 FW/HW 및 드라이버 통신형 | 미확인 |
| 모터 명판 상전류·스텝각·출고 상 결선/교정 이력 | 미확인 |
| 전원공급기 현품·실측 전압·전류제한·퓨즈·급전 차단 | 미확인 |
| 전원 켤 때 자동 복귀/이전 운전 재개 여부 | 미확인 |
| 감속기 감속비·체결 상태·무부하 회전 범위 | 미확인 |
| 임시 RS485 시험 펌웨어와 통신 설정 | 미구현/미확정 |

현재 CAN 설정500k를 RS485 baud 값으로 옮기지 않는다. RS485 주소·baud·패리티/정지비트·프로토콜은 실제 FW와 매뉴얼에 맞춰 정한다. 원점복귀/자동 시작/연속 회전은 첫 시험에 넣지 않는다.

준비가 끝난 뒤의 순서는 **식별·설정 읽기 → 정지/통신 끊김 동작 확인 → 모터 단독 짧은 저속 이동 → 감속기 무부하 저속 단방향 → 짧은 역방향**이다. 걸림·정지 미확인·예상 밖 움직임이 있으면 더 큰 명령으로 밀어붙이지 않는다. 구체 전류·속도·각도·시간은 위 정격과 감속비 확인 후 시험 계획에서 정한다.

## 6. 나중에 CAN으로 바뀔 것

| 항목 | 임시 시험 | 최종 통합 |
|---|---|---|
| 실제 드라이브 | SERVO42D RS485 | SERVO42D CAN 현품 |
| 통신 단자 | Waveshare A+/B− → MKS RS485 A/B | Waveshare H/L → MKS CAN H/L |
| 송수신 코드 | 별도 임시 UART/RS485 시험 도구 | 기존 CAN 코드에 실제 현품 설정/시험을 반영 |
| 재검증 | 단품 기구 회전/간섭 확인 | CAN ID·bitrate·응답·heartbeat/정지·단절·방향/스케일·실제 제어 주기 |
| 보존할 자료 | 실제 조립/회전/간섭/출력 방향 기록 | 같은 기구 상태인지 대조 후 사용 |

RS485 보드가 배선이나 메뉴 설정만으로 CAN 보드가 된다고 가정하지 않는다. CAN형 드라이브로 교체하며 장착·엔코더 자석/교정 조건을 다시 확인한다. 현재 세트와 다른 모터라면 모터 축/장착 치수·커플링·방향·전류부터 다시 대조한다. RS485의 성공을 CAN 통신·정지 수용으로 이관하지 않는다.
