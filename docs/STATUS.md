# 현재 검증 상태

기준일: 2026-11-13 KST. 이 문서는 과거 계획서보다 현재 검증 범위를 먼저 설명합니다.

## 실제로 확인한 하드웨어

- 제어기: Waveshare ESP32-S3-RS485-CAN, **U 없는 모델**.
- J5/J6: 사용자 확인 CAN형. 첫 통신 시험은 J5 한 대만 대상으로 수행했습니다.
- 모터 구매 옵션: MKS SERVO42D CAN MT 모터 포함 세트. 개별 모터 단품 모델·정격 상전류는 아직 확인되지 않았습니다.
- 그리퍼: Feetech STS3215 12V TTL. CAN H/L 또는 RS485 A/B에 직접 연결하지 않습니다.

이 결과는 지속 정지·토크 해제·기구 원점·CAL 유효성·배선 보호·정격 검증을 뜻하지 않습니다. 시험 전 사용자가 CAL을 실수로 눌러 움직임을 보고했으며, 이를 로봇의 기계적 원점 설정 성공으로 판정하지 않았습니다.

## 전원과 첫 시험 설정

24V/서플라이 전류 제한1A, 드라이버 Ma800mA는 J5 초기 시험용 잠정 설정입니다. 모터의 확인된 정격값이 아닙니다. 서플라이 입력 전류 제한과 모터 권선의 Ma는 서로 다른 값입니다. 온도·유지 토크·정격 부하 또는 무인 운전의 적합성이 검증되지 않았습니다.

## 제어 소프트웨어

현재 배포한 브리지는 `INFO` 및 명시적 `READ`(31/32/F1/3A)만 허용합니다. 부팅·INFO 시 CAN을 설치하지 않습니다. 조회는 single-shot 한 번, 수신250ms/32프레임 제한이며 세션 후 정리합니다. 회전·설정 쓰기·enable·F3 비활성·F7 정지를 지원하지 않습니다.

다른 폴더의 제어·정지·휴대폰 연결 코드는 HOST/stub 단계의 연구 구현입니다. 관련 시험 결과를 이 조회 앱에 정지 기능이 있거나 실제 모터 운전이 검증된 것으로 확대하지 않습니다. CR_vFOC 모드에서의 일반 읽기 성공은 CAN 구동 모드 전환이나 동작 검증을 뜻하지 않습니다.

## 시뮬레이션과 기구

URDF v4에는 MP18 형상과 165mm 아래팔, 구성별 추정 물성·KG1 그리퍼를 반영했습니다. 물성은 실측이 아니며 관절 한도가 모든 조합 자세의 책상·자가충돌을 막아주지 않습니다.

137 단위의 피니언 기준값 수정은 기존133 기록을 재생한 HOST 검증과 오프라인 키트 준비까지 완료했습니다. 새 Isaac 동역학에서 수정본의 실제 피니언 추종·물체 파지·이동 완료는 **NOT_RUN**입니다. 과거 실제 Isaac 영상/기록과 이 최신 수정본의 수용을 구분합니다.

카메라를 이용한 첫 관절 이동은 준비 요청 단계입니다. 카메라 앱 실행 보고는 있으나 로봇·책상 간격을 확인한 화면은 아직 확보하지 못했습니다. 이후 에이전트의 실물 동작·모드 변경·업로드는 없습니다. 간헐적 화면 확인을 연속 충돌 감시나 즉시 정지 장치로 사용하지 않습니다.
