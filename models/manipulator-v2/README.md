- 결정 원문 = `.dev/mp18-evidence/user-decisions-mp18.json`: 「하나 더 궁금한건 지금 저기 저 초안 디자인처럼 모델링 수정은 안되?」 → 질문 창 「셸(껍데기) 추가 (권장)」 · 「MP17 커밋 후 MP18 로 (권장)」 → 셸 개념 그림에 「뭔가 다르지않아?? 전면적으로 디자인 개선을 시작해」 · 「이미 출력된거 안써도되니깐 구매품만 그대로 쓴다면괜찬아」 → 개념 B 그림에 「B 로 진행 · 손목까지 (권장)」.
- 원천 = `src/cad/manipulator-v2/`(MP17 생성기 · 검사기 · 출력 준비 · 하중 · 그림을 복사해 고침 — **MP17 파일은 그대로**). 계획 = `.dev/mp18-evidence/plan-mp18.md`.
- 작업 폴더의 개념 그림(커밋 안 함)으로 v3 · MP17 · 개념 B 를 같은 쪽에서 견줘 고른 뒤 본설계했다.
- **MP18 이어서(57D 단자 · 케이블 길)** — 결정 원문 = `.dev/mp18-evidence/user-decisions-mp18-cable.json`: 마무리 물음 「57D 단자 · 케이블 길 설계를 언제 할까요?」 에 「2」(= 「42D 단자 배치를 57D 에도 가정해 지금 바로」) → 개념 그림 뒤 질문 창 「A · 막대 높이 키움 (권장)」 · 「±170° 유지 (권장)」 — 아래 「57D 단자 · 케이블 길」 절.

## 57D 단자 · 케이블 길 (MP18 이어서 — 결정 원문 = `.dev/mp18-evidence/user-decisions-mp18-cable.json`)

MP18 산출 검토 R1-2(57D 단자 자리 없음) · R1-3(케이블 길 없음)을 닫았다. **57D 는 아직 없어 42D 배치를 옮긴 가정**이다(실측하면 `parameters.json` v2.term57 만 바꿔 다시 만든다).

**57D 단자 어림(가정)** — 42D(MP10 다시 만들기 2 · 3 · 사용자 사진 · 글 · 실측 · 모터 원장)를 그대로 옮김:
- 드라이버를 뒤에서 볼 때 **위 = 모터 4 단자**(그 아래 몸통 면에 모터 6 핀 커넥터 — 몸통 뒤 끝에서 11 앞부터 · 높이 10 · 폭 16) · **왼쪽 = 5+2 단자대(CAN H / L 쪽)** · **오른쪽 = 6 단자대(V+ / GND 쪽)** · 아래 = 화면 · 단추.
- 단자대 · 4 단자는 드라이버 면에서 **12 mm**(선 굽힘 포함 · 원장 connector_clearance) · 띠 ±11 · 드라이버 폭 = 몸통 + 3.7(42D 원장 46 − 42.3) · 칸 틈 0.5.
- 방향(J2 · J3 같음): 위(커넥터)가 −x(J2 = 뒤 · J3 = J2 쪽) · **화면은 관절 축 쪽**(조립 뒤 못 봄). J2 = 전원 아래 · CAN 위 / J3 = 전원 위 · CAN 아래.
- 검사용 어림 몸체 = `REF.J2/J3.DRIVER57` · `TERM57_TOP / LEFT / RIGHT / CONN`(C4 · C5 · C9 에 들어감) · **J3 드라이버 · 단자 어림은 벨트 홈 두 끝에도**(+2.5 = 장력 쪽 · -1.5 — 검토 R1-4: 더 J3 쪽(−2.0)은 가정 드라이버가 J3 모듈 뚜껑에 닿음).
