# 082 후속 제안 — 로봇의 힘·모멘트 평형과 PD 식별

상태: 제안만 저장, 구현·HOST·SDK·새 실행 예산 미승인/미실행. 081 원장과 기준·계보를 보존한다.

081은 무연결 COM0 1축에서 PD-only와0.01Nm한계를 확인했다. 이것은 비영COM·다관절 로봇의 projected wrench 기준점/프레임이나 combined의 실제외부기여를 식별하지 못한다. 기존6고정 frame/COM 후보의 단순보정도 여러관절에서 일치하지 않아 채택하지 않았다. robot PD/포화를 미확정으로 유지한다.

제안 순서:

1. 기존 실제 q/qd/pose·질량/COM/관성·joint frame·raw6D의 단위/좌표/기준점 계약을 다시 대조한다. 입력시점·부호·분석값과직접측정을 분리한다.
2. robot에 적용할 수 있는 별도 비영COM·다른 회전축 기준물을 설계한다. 평행축정리·중력 virtual work·힘/모멘트 이동식을 독립 계산하고, 잘못된 축/부호/기준점 음성대조를 먼저 검토한다. 원 로봇 시험의 허용기준을 바꾸지 않는다.
3. 설치 SDK가 지원하는 mass matrix/C/G·가속도/속도·구속 기여를 확인해 전체 동역학 평형 대조 경로를 계획한다. 유한차분 추정과 실제 SDK 측정을 구분하며, body damping·friction·limits/contact·armature·외부기여가 식별되지 않으면 PD residual은 여전히UNKNOWN이다.
4. 필요한 별도 기준 시험의 source/관측 의미를 비작성자가 검토한 뒤, 유효한 토크 관측이 확보되면 원 정착 실패와 포화를 대조한다. drive/게인/cap/경로 수정 후보와 원인 확인 실험은 분리해 제시한다.

현재는 실제실행·변경이 없다. 관측부를 수리해 물리FAIL을 PASS로 올리지 않으며, SDK설치·실물보정·모터/CAN·재부팅·구매·학습도 제외한다. 081의기준물성공과로봇원인미확정을다른축으로보존한다.
