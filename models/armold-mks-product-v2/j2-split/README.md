처분 뒤 둘째 판). 오늘은 출력하지 않습니다. 감속기는 공간만 두고(방식은 계획 014 의 B3 — Mech-Sparring 비교 뒤), 끼움 치수는 끼움 시험편
(`models/fit-coupons-v1/`)의 판정 전까지 **가정값**입니다.

- 만들기 = `src/cad/armold-mks-product-v2/build_j2_split.py --cli <solidcraft-cli.exe>` · 검사 = 같은 폴더의 `check_j2_split.py`(이 폴더의 `validation.json`).
- 좌표 = J2 의 지역 좌표: 출력 축 +Z(= Link2 의 +Y) · 관절 중심이 원점 · 출력 면 z = +18(드럼 깊이 36 의 절반) · +X = Link2 의 +X(표시 자세에서 상완이
  뻗는 쪽) · +Y = −(Link2 의 +Z). 표시 자세의 A2 조립에서 이 +Z 는 v1 `kinematics.json` 의 J2 축 = 세계 [-0.2588, 0.9659, 0] 이다(J1 의 표시 회전 15° 가
  들어간다 — 세계 +Y 가 아니다).
- 파일: `j2-split.solidcraft`(편집 이력 · 부품 여섯 + 참조 몸체 다섯 + A2 의 자식 링크 허브 · 관 + 검사용 A2 외곽 셋) · `j2-split.step` ·
  `parts/<부품>.stl`(부품마다 · J2 좌표 그대로 — 출력 방향은 아래 표대로 돌려 놓는다) · `iso.png`(A2 외곽 숨김 · 자식 링크는 윤곽만) · `section.png`(XZ 면

## 검사 (`validation.json` — 열 모두 참이면 종료 값 0)

만들기(`build_j2_split.py`)의 다섯과 `check_j2_split.py` 의 다섯:

- 검사 못 한 쌍 0 · 부품끼리 체적 간섭 0 · 참조(모터 · 드라이버 · 커넥터 · 감속기 공간 · 베어링 자리)와 부품 간섭 0 · **A2 의 자식 링크(허브 · 관)와 부품
  간섭 0**(L4 R1 F1 뒤 더함).
  - 정확 커널 간섭(`inspect.interference`)이 못 한 쌍은 부품끼리면 틈 검사(`inspect.clearance`)로, 그것도 못 하면 내보낸 부품 STL 끼리의 교차(manifold3d)로
    가른다(교차 부피 0.01 mm³ 이하 = 닿음). 이번 판에서 그렇게 가른 쌍 = 뒤 하우징 ↔ 끝 덮개 하나(두 검사 모두 「no result」 — 끝 덮개의 턱이 캔 안에 0.15
    틈으로 같은 축에 낀 꼴 · 메시 교차 부피 8.6e-15 mm³ · 상자 두께 0 = z −85 의 같은 평면에서 닿음). 같은 함수를 같은 부품끼리 돌리면 그 부피(27 356)가
    나온다(작성자의 양성 대조 · 저장소에 기록하지 않음).
- 부품이 A2 의 J2 외곽(모듈 ∪ 색 링 ∪ 끝 덮개 — 같은 지역 좌표로 다시 그림) 안. 예외 없음(첫 판은 출력 플랜지가 0.5 밖이었다 — F1).
  - 외곽은 원점 기준으로 0.1 % 키워서 본다(r52 에서 0.052 mm · z −91 에서 0.091 mm 여유) — 부품과 외곽의 면이 겹치면 정확 커널의 교차가 실패하기
    때문이다. 이 여유보다 작은 튀어나옴은 이 검사로 가르지 못한다.
  - 「안」 의 허용 = 부품 부피의 1e-5(곡면 부피의 테셀레이션 잡음 — 첫 판의 끝 덮개 eval 부피가 해석값과 1.25e-5 달랐다).
- 부품마다 정확 커널의 셸 1 · 부피 양수 · STL 닫힘 · 조각 하나.
- J2 의 모터 · 드라이버 · 커넥터 가정 상자의 모서리가 캔 속(반지름 37 · z −85 .. −18) 안 · 기둥 셋은 상자를 피한다(부품 ↔ 참조 간섭 0).
- 설계 치수로 적은 최소 벽 두께가 모두 1.2 이상(가장 얇은 곳 = 누름판 자리파기 밑 1.3 · 색 링 위 1.35 · 이음 인서트 구멍과 감속기 공간 사이 1.9 · 기둥의
  인서트 구멍 둘레 1.9 — 전체 = `split.json` 의 `min_wall_mm`).
- 자리파기 · 나사 구멍의 틈이 모두 양수(뒷벽 R5 둥글림까지 0.5 · 캔까지 1.5 · 끝 덮개 R3 둥글림까지 0.4 · 덮개 턱까지 1.65 · 누름판 안 · 바깥 가장자리까지
  5.9 · 2.9 · 누름판 안쪽 ↔ 플랜지 5.5).
  - 첫 판은 이음 볼트 원이 r48 이라 자리파기가 뒷벽 둥글림에 걸렸다(볼트 머리가 곡면에 앉고, STL 에 찌꺼기 삼각형) — 이 검사기가 잡아 r43.5 로 줄였다.
- 부품마다 출력 방향이 적혀 있음.
