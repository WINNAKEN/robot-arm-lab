## 검증과 게시

1. L2는 공개 필터/식별정보 제거/원본 보존/재현성의 논리 결함을 검토한다.
2. 내보내기와 별도 공개 검사로 금지 경로·바이너리·토큰·실제 네트워크 endpoint·파일 크기·URDF mesh 참조를 확인한다. 금지/알 수 없는 바이너리는 실패 처리한다.
3. 현재 reader144 HOST 회귀는 실제 CAN/USB 없이 실행한다. 공개 조회 성공 기록은 ID1/500K/0RPM 한 번의 응답만 뜻하며 실제 움직임·정지 기능·원점 검증은 미완료임을 표시한다.
4. 비작성자 L4가 공개 트리와 검사 결과를 실제 읽고 개인정보/외부 권리/허위 수용/누락을 확인한다. PASS 전에는 외부 생성/업로드를 하지 않는다.
5. 승인된 공개 트리만 새 Git history의 main에 커밋하고 `WINNAKEN/robot-arm-lab` public 생성/push한다. CLI 인증 계정과 저장소 부재를 사전 조회했다. force push 없이 원격 visibility/commit/tree를 다시 읽어 완료를 판정한다.
6. 원본에는 공개 경로와 동기화 절차만 인계한다. 원본 history를 public remote로 바로 연결하지 않는다.
