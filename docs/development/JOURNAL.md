## 2026-11-12 — 조회 전용 ESP 배포와 첫 CAN 응답

ESP의 기존 flash를 로컬에 보존한 뒤 새 조회 앱을 준비했습니다. SDK 전달 방식의 문제로 첫 배포 시도가 flash 쓰기 전에 실패했고, 전달 호출만 수정한145 단위에서 앱/OTA 선택 정보 배포와 readback을 완료했습니다. 원래 bootloader·파티션·NVS를 보존했습니다. 원본 덤프는 공개하지 않습니다.

HOST322검사 및 오류 대조군을 확인했고 실제 USB INFO로 앱 식별·제한된 부팅 안정성을 확인했습니다. 이어 사용자 메뉴값 CR_vFOC·ID1·500K에 맞춰 속도 읽기 한 번을 수행해 정상 체크섬의0RPM 응답을 받았습니다. Mode를 바꾸거나 회전·enable·설정 쓰기를 보내지 않았습니다.

사용자가 앞서 CAL을 눌러 움직인 사건은 별도 기록했습니다. CAL과 로봇의 기구 원점 확정은 구분하며, 통신 조회를 위해 다시 CAL하지 않았습니다.
