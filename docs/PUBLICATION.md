# 공개 범위와 재현

이 공개판은 현재 작업 트리에서 자체 소스와 작성 문서를 선별한 스냅샷입니다. 원본188개 로컬 커밋과 해당 Git 객체는 포함하지 않습니다. 원본의 미커밋 파일인 최신 조회 브리지도 공개판에 포함했습니다.

## 포함한 자료

- `src/`: 펌웨어·HOST 시험·시뮬레이션·CAD 생성기와 텍스트 설정.
- `docs/`: 설계·사양·계측/배선 준비 등 자체 작성 문서. `docs/design/`에는 당시 기록이라는 안내를 덧붙였습니다.
- `models/`: 자체 모델의 텍스트 매개변수·설명·출처, 최신 URDF v4의 메시.
- 현재 결과 요약·개발 일지·공개 트리 검증기와 오프라인 CI 설정 예시.

## 공개하지 않은 자료

장치 flash/NVS 원본·복구 이미지, 계정/인증정보, 주문·메일·원사진, 내부 Drive 보관 목록·비공개 리소스 식별자, 연락처/QR이 포함된 브랜드 적용 시안, 로컬 실행/검수 원시 로그, SDK·도구·의존성·빌드 캐시, 외부 CAD/매뉴얼 패키지, Faze4/Thor 원본/변환 형상과 이전 모델의 대용량 바이너리는 포함하지 않습니다. 프로젝트와 무관한 다른 작업 폴더도 포함하지 않습니다.

개인 사용자 경로와 현장 네트워크 식별정보 일부를 공개 예시로 바꿨습니다. `192.0.2.10`, `EXAMPLE_WIFI`, `robot-user`, `C:/Users/USER` 등은 실제 연결 정보가 아닙니다. ESP 자체 AP와 시험 fixture의 의도된 예시 주소는 그대로 둡니다.

## 재현 범위

조회 브리지의 C++ HOST 시험과 공개 파일 형식 검사는 이 저장소만으로 실행합니다. ESP 타깃 빌드는 별도로 설치한 정확한 ESP-IDF5.5.6이 필요하며, 실제 배포에는 장치별 flash·파티션 확인이 필요합니다.

기존 CAD/시뮬레이션 도구는 SolidCraft·Isaac·추가 Python 패키지·과거 원본 자산 또는 `.dev`/`outputs` 증거를 필요로 할 수 있습니다. 공개하지 않은 경로를 참조하는 역사 기록의 해시·seal·원격 실행 프로필은 공개 트리의 활성 권한이나 재현 성공 증거가 아닙니다. 과거 전체 파이프라인의 무수정 실행을 보장하지 않습니다.

URDF v4의 메시·URDF는 제공하지만 원래 CAD/증거 전체는 제공하지 않습니다. 이 폴더의 provenance/ledger는 출처 기록이며 그 파일에 적힌 모든 로컬 입력이 공개본에 있다는 뜻은 아닙니다. 실제 관절 원점·질량·토크·충돌은 실물 보정과 별도 확인이 필요합니다.

## 검증과 갱신

`python tools/check_public_release.py`는 파일 목록·해시, 금지 파일, 텍스트 내 주요 비밀 형식·사용자 경로·클라우드 리소스 URL·현장 tailnet 주소, Python/JSON/XML 문법, STL 헤더·길이, URDF 메시 경로를 확인합니다. 이미지는 사람이 확인한 고정 해시의 팔레트 이미지 한 장만 허용하고 메타데이터 청크도 검사합니다. 이 검사는 모든 형태의 비밀이나 개인 정보를 탐지한다는 보증이 아닙니다.

공개 파일을 고친 뒤 `python tools/check_public_release.py --write-manifest`로 검사를 먼저 통과한 파일 목록을 갱신합니다. 그 후 HOST 시험과 비작성자 검토를 거쳐 공개 변경을 커밋합니다. 로컬 비공개 원본 폴더에는 이 public remote를 직접 연결해 전체 이력을 밀어 넣지 않습니다.

초기 게시에 사용한 인증에는 저장소 접근 권한은 있지만 `workflow` 권한은 없습니다. 추가 OAuth 권한을 요청하지 않고 CI 설정을 `docs/ci/`의 비활성 템플릿으로 제공했습니다. GitHub에서 CI가 실행/통과했다고 주장하지 않으며, 이 초판의 검증은 로컬 및 비작성자 HOST 결과입니다.
